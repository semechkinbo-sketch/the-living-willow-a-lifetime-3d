# The Living Willow: A Lifetime 3D

Grow a weeping willow beside a living pond. Explore it in 3D as the seasons change, day turns to night, rain ripples across the water and winter freezes the pond. Hold the ground near the roots to grow the tree, drag to look around, and tap the sun, moon or storm cloud to change the scene. Built with HTML, CSS and JavaScript.
